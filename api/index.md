# Plugin API reference

Every public type and member of `AcDream.Plugin.Abstractions`, the contract
plugins compile against, generated from the XML comments in the source. Start
with [IPluginHost](AcDream.Plugin.Abstractions.IPluginHost.yml) and
[IAutomationSurface](AcDream.Plugin.Abstractions.IAutomationSurface.yml).
For how to set up a plugin project, see [Writing a plugin](../docs/plugin-development.md).
